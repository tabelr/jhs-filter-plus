# JHS 筛选增强

给 [JHS](https://github.com/Teamper/JHS)（JAV Helper Suite，JavDB / JavBus 增强脚本）叠加的一层自定义筛选与资料库功能，不改动 JHS 本体。

## 前置要求

必须先安装 **JHS 本体 6.5.2**，本脚本在其基础上工作：

- JHS 本体：<https://github.com/Teamper/JHS>（MIT 协议，作者为 Teamper / JHS Contributors）
- 本仓库**不包含** JHS 本体，只包含下面这个增强脚本。

## 安装

1. 浏览器安装 Tampermonkey（或 Violentmonkey）。
2. 先安装 JHS 本体，再打开本仓库的 `JHS-筛选增强.user.js`，确认安装。
3. 打开 JavDB / JavBus 列表页即可使用，入口在页面右侧导航区（资料库、图墙）。

## 功能

- **图墙筛选**：按状态、评分、年份、添加时间、演员、导演、系列、番号前缀、关键词筛选；支持紧凑 / 标准两种密度、筛选预设、维度内搜索。
- **资料库**：合并 JHS 记录与本地影子库，支持列显示 / 隐藏、排序、紧凑 / 标准密度。
- **补齐**：批量从详情页补齐导演、片商、系列、类别等字段，自适应节流，失败降速，可中途停止；单条可点“补齐”按新番号重抓。
- **未补齐筛选**：一键只看未补齐的记录，番号旁标注原因（失败×N / DB 无收录 / 解析不全 / 缺字段）。
- **查询番号**：资料库内可直接改某条记录的 DB 查询番号（别名），改完点旁边“补齐”即可按新番号抓取。
- **同步 Jellyfin**：把本地资料库识别出的 Jellyfin 番号标为已存。

## 数据与隐私

- 记录存在浏览器本地（油猴存储），不收集账号、密码。
- 补齐时会请求 JavDB / JavBus 的详情页，只读公开页面信息。

- **3.5.0**：界面与框体优化：设计变量化、深色模式、图墙密度切换、筛选条件栏、预设、维度内搜索、资料库列显示 / 隐藏与密度切换、首列固定。
